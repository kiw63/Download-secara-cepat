Alur kompilasi

  
01Kamera depan mengenali dan membandingkan wajah secara otomatis dengan profil di IndexedDB browser ini.

  
02GitHub token memberi otorisasi sebenarnya ke repository dan workflow.

  
03GitHub Actions memakai Java 17, Android SDK 35 dan Gradle untuk membangun APK.

  
04APK signed diperiksa oleh apksigner, tersedia sebagai Release dan Artifact.

  

  
Batas keamanan

  
Pencocokan wajah otomatis tanpa tantangan gerakan bukan deteksi keaslian wajah atau sistem anti-deepfake. Profil IndexedDB dapat dimodifikasi pada perangkat, sehingga perlindungan build sebenarnya tetap pada izin token GitHub. Izin GitHub pada token adalah pengaman build yang sebenarnya.

  
Batas input
ZIP wajib berisi website statis; kode PHP, backend Node, atau source Android mentah tidak otomatis berubah menjadi APK. Jika source memakai Vite/React, unggah ZIP dari folder dist setelah build.

  
Persyaratan layanan
Website: GitHub Pages HTTPS. Kompilasi: GitHub Actions aktif di repository target. Untuk repositori privat, pengguna harus punya izin yang sesuai. Model AI wajah memerlukan unduhan internet saat verifikasi.

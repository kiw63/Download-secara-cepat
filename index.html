⚙️ Pengaturan API

Aplikasi ini otomatis mencoba semua API di bawah. Jika ingin menambahkan Worker sendiri (paling stabil), tempel URL-nya di sini.

1. Buka dash.cloudflare.com → Workers → Create
2. Tempel kode Worker (buka github.com/basstimam/trauso untuk referensi)
3. Tambah Secret TERABOX_COOKIE dengan cookie ndus dari terabox.com
4. Deploy → copy URL → tempel di kolom atas

Info:
• Multi-API: Aplikasi otomatis coba semua API sampai berhasil.
• Mode Turbo: 16 koneksi paralel + tulis langsung ke disk (Chrome/Edge desktop).
• File 3GB+: Aman, tidak pakai RAM.
• Tombol ⚙️ API di kanan atas untuk tambah Worker sendiri jika API publik gagal.

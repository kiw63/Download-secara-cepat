Data lokal di perangkat ini

Blink tahap awal membaca koleksi lokal dari IndexedDB BlinkLocal_v1 dan tidak menghapusnya. Jika video lamamu masih berada di aplikasi VaultBox lama, datanya memakai database terpisah VaultBoxDB_Local_v4 yang terenkripsi; video itu tidak otomatis muncul di UI baru ini. HTML VaultBox lama disertakan di folder legacy/ sebagai cadangan. Jangan hapus data browser atau file lama sebelum proses migrasi diverifikasi.
